## Common argument forms [#common-forms]

All three functions accept the following two calling conventions.

```ts forms.ts
// Positional form
callFnOnce(cacheMap, key, fn);

// Options form
callFnOnce({ cacheMap, key, fn });
```

The positional and options forms share the same cache. Pick whichever reads better at each call site.
