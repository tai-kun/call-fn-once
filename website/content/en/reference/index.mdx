| --- | --- | --- |
| `callFnOnce` | Synchronous values | Shares the result of synchronous work |
| `callAsyncableFnOnce` | Synchronous and asynchronous values | Also shares an in-flight `Promise` |
| `callAbortableFnOnce` | Synchronous and asynchronous values | Additionally supports aborting |

## Common argument forms [#common-forms]

All three functions support the following two ways of calling.

```ts forms.ts
// Positional arguments
callFnOnce(cacheMap, key, fn);

// Options object
callFnOnce({ cacheMap, key, fn });
```

The positional and options forms share the cache. Choose whichever reads better at each call site.

## Error classes [#error-classes]

All three functions synchronously throw common error classes that indicate misuse or inconsistency. For the list and how to identify them, see [Error classes](/reference/errors).
