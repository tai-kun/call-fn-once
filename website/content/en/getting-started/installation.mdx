## Requirements [#requirements]

- Node.js 24 or later is recommended.
- ESM only (`import` / `export`). It cannot be loaded with CommonJS `require`.
- TypeScript type definitions are bundled. No extra setup is needed.

## Adding the package [#install]

```package-install
npm i call-fn-once
```

:::note
`abort-signal-utils` and `maypromise` are installed as dependencies. Both are lightweight and framework-independent.
:::

## Import [#import]

Import only the functions you need.

```ts example.ts
import {
  callAbortableFnOnce,
  callAsyncableFnOnce,
  callFnOnce,
} from "call-fn-once";
```

| Function | When to use it |
| --- | --- |
| `callFnOnce` | Run sync-only work exactly once |
| `callAsyncableFnOnce` | Mix sync and async work |
| `callAbortableFnOnce` | Abort in-flight work |
