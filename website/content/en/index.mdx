A small TypeScript utility that runs a callback function once per key, caches the result, and shares it. It provides three functions you can choose from to match your use case.

## Features [#features]

- Manages execution results with a combination of a key and a `Map`.
- Shares synchronous values as-is and in-flight `Promise`s for asynchronous values.
- Does not cache failed results, so the next call can run again.
- In the abortable function, internal work is aborted only when every waiting caller has aborted.
- Lightweight dependencies and no dependency on a specific framework.

## Choosing among the three functions [#choosing-a-function]

| Function | Use case | Sync | Async | Abort |
| --- | --- | --- | --- | --- |
| `callFnOnce` | Memoize synchronous work | ○ | — | — |
| `callAsyncableFnOnce` | Mix of synchronous and asynchronous work | ○ | ○ | — |
| `callAbortableFnOnce` | Work that needs to support abort | ○ | ○ | ○ |

If you are unsure which to choose, use `callFnOnce` for purely synchronous work, `callAsyncableFnOnce` when asynchronous work is involved, and `callAbortableFnOnce` when callers must be able to abort. For a detailed walkthrough, see [Choose a function that fits your use case](/how-to/choose-a-function).

## Quick start [#quick-start]

```ts
import { callFnOnce } from "call-fn-once";

const cacheMap: callFnOnce.CacheMap = new Map();

const first = callFnOnce(cacheMap, "config", () => {
  return { timeout: 3000 };
});

const second = callFnOnce(cacheMap, "config", () => {
  throw new Error("the second call never runs");
});

console.log(first === second);
```

The second call does not run the callback and returns the first result as-is. If you prefer to learn by doing, start with the tutorial.
