## Requirements [#requirements]

- Node.js 24 or later is recommended.
- ESM (`import` / `export`) only. It cannot be loaded with CommonJS `require`.
- TypeScript type definitions are bundled. No additional setup is needed.

## Add the package [#install]

```package-install
npm i call-fn-once
```

:::note
Dependencies are added along with it. They are all lightweight and do not depend on a specific framework.
:::

## Import the functions [#import]

```ts
import {
  callAbortableFnOnce,
  callAsyncableFnOnce,
  callFnOnce,
} from "call-fn-once";
```

You can import only the functions you use. If you are unsure which to use, see [Choose a function that fits your use case](/how-to/choose-a-function).
