## 動作環境 [#requirements]

- Node.js 24 以上を推奨します。
- ESM (`import` / `export`) 専用です。CommonJS の `require` では読み込めません。
- TypeScript の型定義を同梱しています。追加の設定は不要です。

## パッケージを追加する [#install]

```package-install
npm i call-fn-once
```

:::note
依存パッケージもあわせて追加されます。いずれも軽量で、特定のフレームワークには依存しません。
:::

## 関数をインポートする [#import]

```ts
import {
  callAbortableFnOnce,
  callAsyncableFnOnce,
  callFnOnce,
} from "call-fn-once";
```

使う関数だけを読み込めます。どれを使うか迷ったら、[用途に合う関数を選ぶ](/how-to/choose-a-function)を参照してください。
