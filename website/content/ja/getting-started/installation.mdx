## 動作環境 [#requirements]

- Node.js 24 以上を推奨します。
- ESM（`import` / `export`）専用です。CommonJS の `require` では読み込めません。
- TypeScript の型定義を同梱しています。設定は不要です。

## パッケージの追加 [#install]

```package-install
npm i call-fn-once
```

:::note
依存パッケージとして `abort-signal-utils` と `maypromise` が一緒に追加されます。どちらも軽量で、フレームワークには依存しません。
:::

## インポート [#import]

用途に合わせて必要な関数だけを読み込めます。

```ts example.ts
import {
  callAbortableFnOnce,
  callAsyncableFnOnce,
  callFnOnce,
} from "call-fn-once";
```

| 関数 | 使う場面 |
| --- | --- |
| `callFnOnce` | 同期処理だけを一度だけ実行したい場合 |
| `callAsyncableFnOnce` | 同期と非同期が混在する場合 |
| `callAbortableFnOnce` | 実行中の処理を中断したい場合 |
