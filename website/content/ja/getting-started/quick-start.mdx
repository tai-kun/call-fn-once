このページでは `callFnOnce` を例に、最小限の使い方を説明します。ほかの 2 つの関数も、引数の渡し方は同じです。

## 基本的な使い方 [#basic-usage]

<Steps>
  <Step title="CacheMap を用意する">
    実行結果を保持する `Map` を作成します。結果はキーごとに独立してキャッシュされます。

    ```ts cache.ts
    import { callFnOnce } from "call-fn-once";

    const cacheMap: callFnOnce.CacheMap = new Map();
    ```
  </Step>
  <Step title="キーと関数を渡して実行する">
    同じキーで呼び出すと、2 回目以降は関数を実行せずに結果を返します。

    ```ts
    import { callFnOnce } from "call-fn-once";

    const cacheMap: callFnOnce.CacheMap = new Map();
    let callCount = 0;

    const first = callFnOnce(cacheMap, "config", () => {
      callCount += 1;

      return { timeout: 3000 };
    });

    const second = callFnOnce(cacheMap, "config", () => {
      callCount += 1;

      return { timeout: 9999 };
    });

    console.log(first);
    console.log(first === second);
    console.log(callCount);
    ```

    `first` と `second` は同じ参照になり、`callCount` は `1` のままです。
  </Step>
  <Step title="キーごとに使い分ける">
    キーが異なれば、それぞれ一度ずつ実行されます。

    ```ts
    import { callFnOnce } from "call-fn-once";

    const cacheMap: callFnOnce.CacheMap = new Map();

    const a = callFnOnce(cacheMap, "a", () => "A");
    const b = callFnOnce(cacheMap, "b", () => "B");
    const cachedA = callFnOnce(cacheMap, "a", () => "A2");

    console.log(a);
    console.log(b);
    console.log(cachedA);
    ```
  </Step>
</Steps>

## オプション形式 [#options-form]

引数が多い場合や、キーと関数をまとめたい場合は、オブジェクト形式でも渡せます。この形式でも位置引数とキャッシュを共有できます。

```ts
import { callFnOnce } from "call-fn-once";

const cacheMap: callFnOnce.CacheMap = new Map();

const first = callFnOnce({
  cacheMap,
  key: "config",
  fn: () => ({ timeout: 3000 }),
});

const second = callFnOnce(cacheMap, "config", () => ({ timeout: 9999 }));

console.log(first === second);
```

:::tip
どちらの形式でも動作は同じです。呼び出し箇所ごとに読みやすいほうを選んでください。
:::

## よくある注意点 [#notes]

- `undefined` も正しくキャッシュします。存在確認に `has()` を使っているためです。
- 同期例外が投げられた場合はキャッシュしません。次回呼び出しで再実行されます。
- `CacheMap` ごとにキャッシュは独立します。用途が異なる場合は `Map` を分けてください。
