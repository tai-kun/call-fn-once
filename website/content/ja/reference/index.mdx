## 引数形式の共通点 [#common-forms]

3 つの関数はいずれも、次の 2 通りの呼び出しに対応します。

```ts forms.ts
// 位置引数形式
callFnOnce(cacheMap, key, fn);

// オプション形式
callFnOnce({ cacheMap, key, fn });
```

位置引数とオプション形式はキャッシュを共有します。呼び出し箇所ごとに読みやすいほうを選んでください。
