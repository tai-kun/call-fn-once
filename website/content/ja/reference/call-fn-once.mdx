---
title: callFnOnce
description: 同期関数をキーごとに一度だけ実行し、結果を共有するための関数の仕様です。
---

指定されたキーごとに、コールバック関数を一度だけ実行して結果をキャッシュします。2 回目以降の呼び出しでは、再実行せずにキャッシュされた結果を返します。

## 使い方 [#usage]

```ts
import { callFnOnce } from "call-fn-once";

const cacheMap: callFnOnce.CacheMap = new Map();

const result = callFnOnce(cacheMap, "key", () => 42);
```

オプション形式でも同じ結果が得られます。

```ts options.ts
import { callFnOnce } from "call-fn-once";

const cacheMap: callFnOnce.CacheMap = new Map();

const result = callFnOnce({
  cacheMap,
  key: "key",
  fn: () => 42,
});
```

## 仕様 [#behavior]

- `undefined` の結果もキャッシュします。存在確認に `has()` を使うためです。
- キャッシュしたオブジェクトは同一参照で返します。
- 同期例外が投げられた場合はキャッシュしません。次回呼び出しで再実行されます。
- キーごとに独立してキャッシュします。
- `CacheMap` ごとに独立します。用途が異なる場合は `Map` を分けてください。
- 同一 `Map` の同一キーは、コールバック関数の同期的な実行中に再び呼び出せません。再入は `ReentrantCallError` を同期的に投げます。避けるにはキーを分けてください。詳しくはエラー処理を見てください。
- 別の関数で同じ `CacheMap` を使うと、キーによらず `MismatchedCacheMapError` を同期的に投げます。関数ごとに `Map` を分けてください。

```ts
import { callFnOnce } from "call-fn-once";

const cacheMap: callFnOnce.CacheMap = new Map();
let callCount = 0;

callFnOnce(cacheMap, "key", () => {
  callCount += 1;

  return undefined;
});

const cached = callFnOnce(cacheMap, "key", () => {
  callCount += 1;

  return "second";
});

console.log(cached);
console.log(callCount);
```

:::warning
非同期関数を渡すと、`Promise` オブジェクト自体がキャッシュされます。解決待ちの共有や拒否時の再実行は行いません。非同期処理を含む場合は `callAsyncableFnOnce` を使ってください。
:::

## 型定義 [#types]

    },
    fn: {
      type: "() => V",

    },
  }}

`callFnOnce.CacheMap` が求めるのは `has()`・`get()`・`set()` だけです。`Map` と `WeakMap` をそのまま渡せます。`delete()` は要求しません。`WeakMap` のキーにはオブジェクトだけを指定できます。

戻り値の型は `callFnOnce.Return<V>` で、`V` と同じになります。

```ts types.ts
import { callFnOnce } from "call-fn-once";

const numberCacheMap: callFnOnce.CacheMap<string, number> = new Map();
const undefinedCacheMap: callFnOnce.CacheMap<string, undefined> = new Map();

const num: number = callFnOnce(numberCacheMap, "num", () => 1);
const nothing: undefined = callFnOnce(undefinedCacheMap, "nothing", () => undefined);
```

### 型推論 [#type-inference]

戻り値の型は、コールバック関数が返す値ではなく、`CacheMap` の型引数 `V` から決まります。`key` の型も `CacheMap` の型引数 `K` で制約されます。

仮にコールバック関数の戻り値から型を推論した場合、同じキーに対して呼び出しごとに異なる戻り値の型で呼び出せてしまいます。次のコードでは、2 回目の呼び出しは `string` 型と推論されますが、実際に返るのは 1 回目にキャッシュされた `number` の `42` です。

```ts unsafe.ts
import { callFnOnce } from "call-fn-once";

const cacheMap: callFnOnce.CacheMap = new Map();

const value1: number = callFnOnce(cacheMap, "key", () => 42);
console.log(value1); // 42

const value2: string = callFnOnce(cacheMap, "key", () => "42");
console.log(value2); // 42
```

この制約を有効にするには、`CacheMap` の型引数でキーと値を指定します。たとえば `CacheMap<string, number>` を指定すると、同じキーに対して `string` を返すコールバック関数はコンパイルエラーになります。

```ts typed.ts
import { callFnOnce } from "call-fn-once";

const cacheMap: callFnOnce.CacheMap<string, number> = new Map();

const value1: number = callFnOnce(cacheMap, "key", () => 42);

// 型エラー: 同じキーに対して string は返せません。
const value2: string = callFnOnce(cacheMap, "key", () => "42");
```

`CacheMap` とだけ書いて型引数を省略すると、`V` は `any` になり、制約がかかりません。型の制約が必要な場合は型引数を指定してください。
