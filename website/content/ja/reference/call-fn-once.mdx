---
title: callFnOnce
description: 同期関数をキーごとに一度だけ実行し、結果を共有するための関数の仕様です。
---

指定されたキーごとに、コールバック関数を一度だけ実行して結果をキャッシュします。2 回目以降の呼び出しでは再実行せずにキャッシュされた結果を返します。

## 使い方 [#usage]

```ts
import { callFnOnce } from "call-fn-once";

const cacheMap: callFnOnce.CacheMap = new Map();

const result = callFnOnce(cacheMap, "key", () => 42);
```

オプション形式でも同じ結果が得られます。

```ts options.ts
import { callFnOnce } from "call-fn-once";

const cacheMap: callFnOnce.CacheMap = new Map();

const result = callFnOnce({
  cacheMap,
  key: "key",
  fn: () => 42,
});
```

## 仕様 [#behavior]

- `undefined` の結果もキャッシュします。存在確認に `has()` を使うためです。
- キャッシュしたオブジェクトは同一参照で返します。
- 同期例外が投げられた場合はキャッシュしません。次回呼び出しで再実行されます。
- キーごとに独立してキャッシュします。
- `CacheMap` ごとに独立します。用途が異なる場合は `Map` を分けてください。
- 同一 `Map` の同一キーはコールバック関数の同期的な実行中に再び呼び出せません。再入は `ReentrantCallError` を同期的に投げます。避けるにはキーを分けてください。
- 別の関数で同じ `CacheMap` を使うと、キーによらず `MismatchedCacheMapError` を同期的に投げます。関数ごとに `Map` を分けてください。

```ts
import { callFnOnce } from "call-fn-once";

const cacheMap: callFnOnce.CacheMap = new Map();
let callCount = 0;

callFnOnce(cacheMap, "key", () => {
  callCount += 1;

  return undefined;
});

const cached = callFnOnce(cacheMap, "key", () => {
  callCount += 1;

  return "second";
});

console.log(cached); // undefined
console.log(callCount); // 1
```

:::warning
非同期関数を渡すと、`Promise` オブジェクト自体がキャッシュされます。解決待ちの共有や拒否時の再実行は行いません。非同期処理を含む場合は `callAsyncableFnOnce` を使ってください。
:::

## 型定義 [#types]

<TypeTable
  type={{
    cacheMap: {
      type: "callFnOnce.CacheMap<K, V>",
      required: true,
      description:
        "実行結果を保持するオブジェクトです。has・get・set だけを要求するため、Map と WeakMap のどちらも使えます。",
    },
    key: {
      type: "K",
      required: true,
      description: "キャッシュを識別する一意のキーです。型は CacheMap の型引数 K で決まります。",
    },
    fn: {
      type: "() => V",
      required: true,
      description: "実行するコールバック関数です。戻り値は CacheMap の型引数 V に合わせます。",
    },
  }}
/>

`callFnOnce.CacheMap` が求めるのは `has()`・`get()`・`set()` だけです。`Map` と `WeakMap` をそのまま渡せます。`delete()` は要求しません。`WeakMap` のキーにはオブジェクトだけを指定できます。

戻り値の型は `callFnOnce.Return<V>` で、`V` と同じになります。

```ts types.ts
import { callFnOnce } from "call-fn-once";

const numberCacheMap: callFnOnce.CacheMap<string, number> = new Map();
const undefinedCacheMap: callFnOnce.CacheMap<string, undefined> = new Map();

const num: number = callFnOnce(numberCacheMap, "num", () => 1);
const nothing: undefined = callFnOnce(undefinedCacheMap, "nothing", () => undefined);
```

戻り値の型はコールバック関数の戻り値ではなく `CacheMap` の型引数 `V` から決まります。`K` と `V` を指定してコンパイル時の誤りを防ぐ方法は、[型引数で安全性を高める](/how-to/type-safely)を参照してください。
